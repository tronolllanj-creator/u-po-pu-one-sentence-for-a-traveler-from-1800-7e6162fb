This repository contains a program that writes one original sentence explaining the modern internet to a traveler from 1800. The shipped sentence is: "The internet is a swift post office where your letter travels to any door on earth before the ink dries, and a single endless library where you can read every book ever written from one chair."

## Run it
```sh
python3 main.py
```
